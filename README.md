# Sodium - YouTube Productivity Extension

A browser extension to help you stop wasting time on YouTube.

## Features

### Shorts Blocker
Hides YouTube Shorts by default — because doom scrolling is a trap.

### Focus Mode
Set a timer from the extension popup; all YouTube video recommendations are hidden until it expires.

### Zen Mode
Hides all thumbnails so you have to read the title to decide if a video is worth watching — no more clickbait.

## Installation

1. Clone this repo
2. Go to `chrome://extensions/` and enable Developer Mode
3. Click "Load unpacked" and select the project folder

## Usage

Click the Sodium icon in your browser toolbar to access the popup and toggle modes.
